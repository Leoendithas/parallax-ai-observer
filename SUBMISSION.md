Project name
Parallax

Description · what does it do?
Parallax is a spatial puzzle game where switching between a rotatable 3D overview and first person changes which paths are solid. Solve six chambers while an Astra agent automatically adapts assistance and difficulty to your play.

How did you use Astra?
I used Astra in Codex to build, test, and deploy the game. In gameplay, an Astra agent through the Agents API evaluates player performance, enabling safety assistance after repeated falls or selecting a harder next chamber after strong solves—all automatically.
